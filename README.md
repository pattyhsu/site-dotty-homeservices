# dottyhomeservices.com

One-page site for Dotty Homeservices, Inc. (CA DRE #02431285). Plain HTML/CSS, served by
GitHub Pages from `main` (see `CNAME`). Pushing to `main` publishes in about a minute.

Designed from the mockup in `dotty-agents/.mockups/dottyhomeservices_site_mockup.html`.

Rules for the copy:
- Past flips were bought and sold by the flip entities, not the brokerage. Credit the
  "Our work" homes to "Dotty Homes and affiliated companies", never to Dotty Homeservices,
  and don't say the brokerage is "the buyer".
- Show the DRE license number anywhere the site advertises real estate.
- No deal counts, purchase prices, sale prices or street addresses.
